# Contribuir

Gracias por colaborar con MCP datos.gob.es.

## Desarrollo

1. Usa Node.js 20+.
2. Instala dependencias con `npm install`.
3. Ejecuta `npm test` antes de enviar cambios.
4. Si el cambio afecta consultas o formatos de la API, valida también con `npm run test:live`.

## Pull requests

- Mantén el servidor independiente de cualquier proveedor de LLM.
- Conserva la compatibilidad de los transportes MCP y documenta cambios de configuración.
- No incluyas secretos, tokens ni credenciales.
- Describe brevemente el cambio y las comprobaciones realizadas.

## Incidencias

Incluye los pasos para reproducir, el transporte utilizado y mensajes de error relevantes. No publiques claves ni datos sensibles.
